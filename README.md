# CiscoOne Experience Lab — Student Guide

Source of the lab user guide, published by GitHub Pages at
**https://imanassypov.github.io/cisco-one-experience-lab-guide/**.

The automation that the guide walks through lives in a separate repository so
students can clone it quickly on the jumpserver:
[imanassypov/cisco-one-experience-lab-automation](https://github.com/imanassypov/cisco-one-experience-lab-automation).

- `index.html` — the guide (hand-edited HTML; opens offline too)
- `automation_images/` — screenshots referenced by the guide
- `verfication/` — sample verification reports linked from the guide
